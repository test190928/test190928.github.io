運営について

「公的オープンデータの整理帳」は、国や自治体が公開しているオープンデータを、探しやすく・比べやすい形に整理して載せるサイト群です。個人が運営しており、国・自治体・データの提供元とは関係ありません。

データの扱い方

  • 使うのは、再配布や加工が認められた公的なオープンデータだけです。各ページの末尾に出典とライセンスを載せています。
  • 数値は元データの値を変えずに載せます。合計・平均・順位・比較など当サイトが計算したものは、そのことを各サイトの「このサイトについて」に書いています。
  • 個人の氏名など、個人を特定できる情報は載せません。

ページの作り方

表と要約の文は、プログラムで元データから作っています。手で数値を書き写すと誤りが入るためです。そのかわり、公開の前に公式の原文と数値を突き合わせ、食い違いが無いことを確かめています（たとえば最低賃金は1,175の値、有効求人倍率は11,515の値、ガソリン・灯油価格は470の値を照合し、食い違いは0でした）。国民健康保険料の計算は、各市区が公開している試算と結果が一致することを確かめた市区だけを載せています。

どの頁にも、元データには無い当サイトの整理（地域ごとの推移・全国との比較・順位・前回比など）を入れています。元データをそのまま写しただけの頁は作りません。

更新

元データの更新に合わせて作り直します。更新の頻度はサイトによって違い、各サイトの「このサイトについて」に書いています。各ページの末尾に、データの時点とページの生成日を載せています。

誤りの報告・問い合わせ

数値の誤り・リンク切れ・掲載内容の削除の依頼は GitHub の Issues で受け付けています（GitHub のアカウントが必要です）。確認して、誤りであれば次の更新までに直します。

アクセス計測

訪問数を知るため、cookie を使わないアクセス計測（Cloudflare Web Analytics）を全サイトで使っています。閲覧者を個人として識別・追跡する情報は集めていません。

プライバシー

アクセス計測と広告の cookie の扱いはプライバシーポリシーに書いています。

ご利用にあたって

元データの誤り・更新の遅れ・当サイトの加工の誤りにより、実際と異なる場合があります。当サイトの情報を使って生じた損害について、運営者は責任を負いません。重要な判断の前には、各ページに記載した公式の情報源をご確認ください。
