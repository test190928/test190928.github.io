バス時刻表

このサイトについて

自治体が GTFS-JP 形式で公開しているコミュニティバスのデータから、バス停ごと・路線ごとの時刻表を作ったサイトです。公式の時刻表は路線ごとの PDF であることが多いため、バス停を選ぶとそこを通る全路線の発車時刻が1ページで見られるようにしています。ページはプログラムで自動生成しています。

データの出典

  • 成田市コミュニティバス: GTFSデータリポジトリ・CC BY 4.0（ダイヤ 2026-04-01〜2026-12-30）

時刻・停留所名・運賃は元データの値をそのまま載せています。

当サイトが整理しているもの

  • 平日＝月曜に運行する便、土休日＝日曜に運行する便です。祝日の扱いは各ページに記載しています。
  • のりばが複数あるバス停は、1つのバス停にまとめています。
  • 終点での到着と、乗車できない停車は「発車」に数えていません。
  • 「前後のバス停」は、いずれかの便でそのバス停の直前・直後に停まるバス停です。

載っていないもの

遅れ・運休・臨時ダイヤ・工事による迂回は反映していません。運行情報は各自治体の公式ページでご確認ください。

更新

ダイヤ改正で元データが更新されたら作り直します。各ページの末尾に、ダイヤの有効期間とデータの版を載せています。

運営者

個人が運営しています。国・自治体・データの提供元とは関係ありません。複数のサイトをまとめて運営しており、全体の方針は運営についてにあります。

誤りの報告・問い合わせ

数値の誤り・リンク切れ・削除の依頼は GitHub の Issues で受け付けています（GitHub のアカウントが必要です）。確認して、誤りであれば次の更新までに直します。

アクセス計測

訪問数を知るため、cookie を使わないアクセス計測（Cloudflare Web Analytics）を使っています。閲覧者を個人として識別・追跡する情報は集めていません。

広告

このサイトには Google AdSense の広告を表示しています。広告の配信に使われる cookie の扱いと無効にする方法はプライバシーポリシーに書いています。

ご利用にあたって

元データの誤り・更新の遅れ・当サイトの加工の誤りにより、実際と異なる場合があります。当サイトの情報を使って生じた損害について、運営者は責任を負いません。重要な判断の前には、各ページに記載した公式の情報源をご確認ください。
