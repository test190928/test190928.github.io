このサイトについて

厚生労働省が公表している地域別最低賃金の改定状況を、都道府県ごとに1ページへまとめ直しています。

出典と利用規約

厚生労働省「地域別最低賃金の全国一覧」に掲載の「平成14年度から令和８年度までの地域別最低賃金改定状況」。厚生労働省ホームページの利用規約（公共データ利用規約 第1.0版に準拠）に従い、加工して掲載しています。

当サイトが計算しているもの

引上げ額・引上げ率・47都道府県の中の順位（同額は同順位）・全国加重平均額との差・最初の年度からの増加。前年度と同額の年度は「改定なし」と表示しています。

載っていないもの

特定（産業別）最低賃金、月給・日給の換算、来年度以降の見込みは載せていません。

更新

厚生労働省が改定状況の表を更新したら作り直します。発効日は厚生労働省の表のとおりです（発効前の年度も日付だけを載せています）。

運営者

個人が運営しています。国・自治体・データの提供元とは関係ありません。複数のサイトをまとめて運営しており、全体の方針は運営についてにあります。

誤りの報告・問い合わせ

数値の誤り・リンク切れ・削除の依頼は GitHub の Issues で受け付けています（GitHub のアカウントが必要です）。確認して、誤りであれば次の更新までに直します。

アクセス計測

訪問数を知るため、cookie を使わないアクセス計測（Cloudflare Web Analytics）を使っています。閲覧者を個人として識別・追跡する情報は集めていません。

ご利用にあたって

元データの誤り・更新の遅れ・当サイトの加工の誤りにより、実際と異なる場合があります。当サイトの情報を使って生じた損害について、運営者は責任を負いません。重要な判断の前には、各ページに記載した公式の情報源をご確認ください。

出典: 厚生労働省「地域別最低賃金の全国一覧」掲載の「平成14年度から令和８年度までの地域別最低賃金改定状況」を加工して作成。 利用規約（公共データ利用規約 第1.0版に準拠）。時間額と発効年月日は原文の値で、引上げ額・引上げ率・順位・全国加重平均額との差は当サイトが計算しています。 本サイトは厚生労働省とは関係がありません。

最低賃金は時間額です。特定（産業別）最低賃金・派遣先の最低賃金など、この表に無いものは各都道府県労働局でご確認ください。
