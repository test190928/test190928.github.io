このサイトについて

自治体がオープンデータとして公開している指定緊急避難場所の一覧を、災害の種類ごと・区ごとに整理したサイトです。ページはプログラムで自動生成しています。

  • 「指定緊急避難場所一覧」（東大阪市・BODIK ODCS、CC BY 4.0）を加工して作成

指定緊急避難場所とは

災害対策基本法にもとづき、市町村が災害の種類ごとに指定する、命を守るために緊急に避難する場所です。同じ場所でも、洪水では指定されていて津波では指定されていない、ということがあります。避難生活を送る「指定避難所」とは別の指定です。

当サイトが計算しているもの

  • 災害の種類ごとの件数・割合（元データの災害種別の列が 1 または ○ のものを「指定あり」、空欄・× を「指定なし」としています）。
  • 区ごとの件数（所在地の表記から区を読み取っています）。
  • 想定収容人数の合計（人数が書かれている場所だけの合計）。
  • その市で1か所も指定がない災害の種類（例: 火山現象）は、元データで空欄のため載せていません。すべての場所で指定されている災害の種類は、市のページの一覧と同じになるため別ページにしていません。
  • 福岡市は、避難所と避難場所が1つのファイルに入っているため、指定緊急避難場所の行だけを使っています。市が公開している別の形式のデータと名称で突き合わせ、災害の種類の指定が違う欄に ※ を付けています。

載せていないもの

電話番号・避難時の連絡先の列は載せていません。開設状況（今開いているか）は元データに無いため、当サイトではわかりません。

更新

元データの更新は自治体ごとに不定期です。当サイトは元データを取り直して作り直します。

運営者

個人が運営しています。国・自治体・データの提供元とは関係ありません。複数のサイトをまとめて運営しており、全体の方針は運営についてにあります。

誤りの報告・問い合わせ

数値の誤り・リンク切れ・削除の依頼は GitHub の Issues で受け付けています（GitHub のアカウントが必要です）。確認して、誤りであれば次の更新までに直します。

アクセス計測

訪問数を知るため、cookie を使わないアクセス計測（Cloudflare Web Analytics）を使っています。閲覧者を個人として識別・追跡する情報は集めていません。

ご利用にあたって

元データの誤り・更新の遅れ・当サイトの加工の誤りにより、実際と異なる場合があります。当サイトの情報を使って生じた損害について、運営者は責任を負いません。重要な判断の前には、各ページに記載した公式の情報源をご確認ください。
