このサイトについて

厚生労働省が公開している介護事業所のオープンデータから、デイサービス（通所介護・地域密着型通所介護）を市区町村ごとに集計し、定員・営業曜日・運営法人つきで一覧にしたサイトです。ページはプログラムで自動生成しています。

データの出典

厚生労働省「介護サービス情報公表システム」オープンデータ（2026年6月末時点）。配布ページ・ライセンス CC BY 4.0。事業所名・住所・電話・定員・営業曜日などは元データの値をそのまま載せています。

当サイトが計算・加工しているもの

  • 対象は通所介護と地域密着型通所介護（定員18人以下の小規模なデイサービス）の2種類です。
  • 定員が空欄または0の事業所は「未記載」とし、定員の合計・平均には含めていません。
  • 地域密着型通所介護で定員が19人以上と記載された事業所（元データで180・216 など）も「未記載」としています。介護サービス情報公表システムの事業所ページと突き合わせたところ、19人以上と記載された7事業所のうち6事業所で利用定員と合わなかった（多くは18人以下）ためです。7事業所のうち1事業所は記載どおりの値だったので、この中には正しい定員も含まれえます。18人以下と記載された5事業所は、すべて事業所ページの利用定員と一致しました。
  • 事業所が5件未満の市町村は、単独のページにせず県のページの下部にまとめています。
  • 件数・土曜営業の割合の順位は、県内の市区町村（政令市は区ごと）の中での順位です。
  • 「近くの市区町村」の距離は、それぞれの事業所の緯度経度の中央値どうしの直線距離の目安です。
  • 事業所のホームページの URL が元データで崩れているものはリンクにしていません。

載っていないもの

空き状況・利用料金・送迎の範囲・評判は元データに無いため載せていません。介護サービス情報公表システムか各事業所、お住まいの地域包括支援センター・ケアマネジャーにご確認ください。

更新

元データは年2回（6月末時点・12月末時点）公開されます。新しい版が出たら作り直します。各ページの末尾に、データの時点とページの生成日を載せています。

運営者

個人が運営しています。国・自治体・データの提供元とは関係ありません。複数のサイトをまとめて運営しており、全体の方針は運営についてにあります。

誤りの報告・問い合わせ

数値の誤り・リンク切れ・削除の依頼は GitHub の Issues で受け付けています（GitHub のアカウントが必要です）。確認して、誤りであれば次の更新までに直します。

ご利用にあたって

元データの誤り・更新の遅れ・当サイトの加工の誤りにより、実際と異なる場合があります。当サイトの情報を使って生じた損害について、運営者は責任を負いません。重要な判断の前には、各ページに記載した公式の情報源をご確認ください。
