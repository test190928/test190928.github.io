このサイトについて

総務省統計局の家計調査の品目別の年間支出金額を、品目ごと・都市ごとに1ページへまとめ直しています。

出典と利用規約

総務省統計局「家計調査」家計収支編 二人以上の世帯 品目分類（2025年改定）年次（e-Stat）。e-Stat 利用規約に従い、加工して掲載しています。このサービスは、政府統計総合窓口(e-Stat)のAPI機能を使用していますが、サービスの内容は国によって保証されたものではありません。

当サイトが計算しているもの

単年の順位（その年に値のある都市の中で金額の多い順・同額は同順位）・全国比・前年比・期間中の増減。

統計局のランキングとの違い

統計局の「品目別都道府県庁所在市及び政令指定都市ランキング」は直近3年の平均で順位を付けています。当サイトは単年の値で順位を付けているため、ニュースなどで伝えられる「1位」と違う年があります。

載っていないもの

数量（グラム）・単身世帯・都道府県全体の値、品目の定義の詳細（家計調査の収支項目分類を参照）。

更新

家計調査の年報が公表されたら作り直します。

運営者

個人が運営しています。国・自治体・データの提供元とは関係ありません。複数のサイトをまとめて運営しており、全体の方針は運営についてにあります。

誤りの報告・問い合わせ

数値の誤り・リンク切れ・削除の依頼は GitHub の Issues で受け付けています（GitHub のアカウントが必要です）。確認して、誤りであれば次の更新までに直します。

アクセス計測

訪問数を知るため、cookie を使わないアクセス計測（Cloudflare Web Analytics）を使っています。閲覧者を個人として識別・追跡する情報は集めていません。

広告

このサイトには Google AdSense の広告を表示しています。広告の配信に使われる cookie の扱いと無効にする方法はプライバシーポリシーに書いています。

ご利用にあたって

元データの誤り・更新の遅れ・当サイトの加工の誤りにより、実際と異なる場合があります。当サイトの情報を使って生じた損害について、運営者は責任を負いません。重要な判断の前には、各ページに記載した公式の情報源をご確認ください。

出典: 総務省統計局「家計調査」家計収支編 二人以上の世帯 品目分類（2025年改定）年次（e-Stat）を加工して作成。 e-Stat 利用規約に従っています。金額は原文の値（1世帯あたり年間支出金額・円）で、順位・全国との比・前年比は当サイトが計算しています。
