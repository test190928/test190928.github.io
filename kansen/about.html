このサイトについて

国立健康危機管理研究機構（JIHS）が毎週公開している感染症発生動向調査の速報データから、定点把握の19疾病について、都道府県ごとの過去1年の推移・全国との比較・順位・前週との差をまとめたサイトです。ページはプログラムで自動生成しています。

データの出典

JIHS「感染症発生動向調査 週報（IDWR）」の速報データ（定点把握疾病・都道府県別）。IDWR・利用規約。報告数と定点当たり報告数は元の表の値をそのまま載せています。

インフルエンザは、JIHS「インフルエンザ疫学情報速報」の都道府県別報告（Excel）が週報の CSV より先に出たとき、その週の値をインフルエンザの頁（都道府県別・都道府県ごとの推移）に先に載せます。週報の CSV と同じ定点当たり報告数で、CSV が出たら CSV に切り替えます。

定点当たり報告数とは

インフルエンザなどの定点把握疾病は、全ての医療機関ではなく、あらかじめ決めた医療機関（定点）からの報告で流行を見ています。定点当たり報告数は「1週間の報告数÷定点の数」で、医療機関1か所あたり1週間に何人の患者が報告されたかを表します。都道府県で定点の数が違うため、比較にはこの値を使います。

当サイトが計算しているもの

  • 全国比＝都道府県の定点当たり÷全国の定点当たり。
  • 順位＝47都道府県の中で定点当たりが大きい順。報告が0の都道府県には順位を付けていません。
  • 前週差＝今週の定点当たり−前週の定点当たり。
  • 推移のグラフと最大値は、直近60週のうち公開されている週から作っています。
  • 元の表の「-」（報告なし）は0として扱っています。

更新

JIHS の週報は毎週公開されますが、公開日は週によって違います。当サイトは毎日公開を確認し、新しい週が出たら作り直します。速報値のため、後に確定値で修正されることがあります。

流行の警報・注意報について

当サイトの数値は警報・注意報ではありません。流行警報・注意報や医療上の判断は、お住まいの都道府県の感染症情報センターの発表と、医療機関の指示に従ってください。

運営者

個人が運営しています。国・自治体・データの提供元とは関係ありません。複数のサイトをまとめて運営しており、全体の方針は運営についてにあります。

誤りの報告・問い合わせ

数値の誤り・リンク切れ・削除の依頼は GitHub の Issues で受け付けています（GitHub のアカウントが必要です）。確認して、誤りであれば次の更新までに直します。

アクセス計測

訪問数を知るため、cookie を使わないアクセス計測（Cloudflare Web Analytics）を使っています。閲覧者を個人として識別・追跡する情報は集めていません。

広告

このサイトには Google AdSense の広告を表示しています。広告の配信に使われる cookie の扱いと無効にする方法はプライバシーポリシーに書いています。

ご利用にあたって

元データの誤り・更新の遅れ・当サイトの加工の誤りにより、実際と異なる場合があります。当サイトの情報を使って生じた損害について、運営者は責任を負いません。重要な判断の前には、各ページに記載した公式の情報源をご確認ください。
