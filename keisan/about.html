このサイトについて

市区ごとの国民健康保険料（税）を、公式の料率と全国共通の規則から計算するサイトです。

出典

料率は各市区の公式頁（令和8年度）。所得の計算（給与所得・年金所得の速算表）・軽減の基準・未就学児と子どもの軽減は全国共通の規則で、さいたま市・世田谷区などの公式頁の記載で確かめています。各市区の頁の「出典と確かめ方」に、市区ごとの頁へのリンクがあります。

計算の確かめ方

市区ごとに、市区の公式の試算（Excel の試算表・ウェブの試算システム）と、年齢・収入・人数を変えた数百〜数千の世帯で計算結果を突き合わせ、区分ごとの年額がすべて一致した市区だけを載せています。

当サイトが計算しているもの

保険料の年額・区分ごとの内訳・軽減の割合・早見表・市区の比較。

載っていないもの

年度の途中の加入・脱退と月割り、擬制世帯主・特定同一世帯所属者、所得金額調整控除の一部、市区の減免、65歳以上の介護保険料。

入力した数字について

計算はすべてお使いのブラウザの中で行い、入力した年齢・収入はどこにも送信・保存しません。

更新

市区が翌年度の料率を決めたら（例年3〜6月）作り直します。

運営者

個人が運営しています。国・自治体・データの提供元とは関係ありません。複数のサイトをまとめて運営しており、全体の方針は運営についてにあります。

誤りの報告・問い合わせ

数値の誤り・リンク切れ・削除の依頼は GitHub の Issues で受け付けています（GitHub のアカウントが必要です）。確認して、誤りであれば次の更新までに直します。

アクセス計測

訪問数を知るため、cookie を使わないアクセス計測（Cloudflare Web Analytics）を使っています。閲覧者を個人として識別・追跡する情報は集めていません。

広告

このサイトには Google AdSense の広告を表示しています。広告の配信に使われる cookie の扱いと無効にする方法はプライバシーポリシーに書いています。

ご利用にあたって

元データの誤り・更新の遅れ・当サイトの加工の誤りにより、実際と異なる場合があります。当サイトの情報を使って生じた損害について、運営者は責任を負いません。重要な判断の前には、各ページに記載した公式の情報源をご確認ください。

料率は各市区の公式頁（各頁の「出典と確かめ方」）の令和8年度の値です。所得の計算・軽減の基準は全国共通の規則（地方税法・国民健康保険法施行令）によります。計算と早見表は当サイトが行ったもので、市区が内容を保証するものではありません。
