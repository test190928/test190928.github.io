このサイトについて

気象庁「過去の気象データ検索」の年ごとの値を、観測所ごとに1ページへまとめ直しています。

出典と利用規約

気象庁「過去の気象データ検索」（年ごとの値・詳細（気温））。気象庁ホームページの利用規約（公共データ利用規約 第1.0版に準拠）に従い、加工して掲載しています。

当サイトが計算しているもの

猛暑日の多い年の順位、10年ごとの平均、1991〜2020年の平均と、その平均に対する比。1991〜2020年の平均は当サイトの単純平均で、気象庁の「平年値」ではありません。

載っていないもの

予報・警報・熱中症の情報は載せていません。今日・明日の気温は気象庁の発表をご確認ください。

更新

気象庁の表をもとに不定期に作り直します。今年の値は年の途中の値です。

運営者

個人が運営しています。国・自治体・データの提供元とは関係ありません。複数のサイトをまとめて運営しており、全体の方針は運営についてにあります。

誤りの報告・問い合わせ

数値の誤り・リンク切れ・削除の依頼は GitHub の Issues で受け付けています（GitHub のアカウントが必要です）。確認して、誤りであれば次の更新までに直します。

アクセス計測

訪問数を知るため、cookie を使わないアクセス計測（Cloudflare Web Analytics）を使っています。閲覧者を個人として識別・追跡する情報は集めていません。

ご利用にあたって

元データの誤り・更新の遅れ・当サイトの加工の誤りにより、実際と異なる場合があります。当サイトの情報を使って生じた損害について、運営者は責任を負いません。重要な判断の前には、各ページに記載した公式の情報源をご確認ください。

出典: 気象庁「過去の気象データ検索」（年ごとの値・詳細（気温））を加工して作成。 利用規約（公共データ利用規約 第1.0版に準拠）。日数は気象庁の表の値をそのまま使い、順位・平均・10年ごとの平均は当サイトが計算しています。 本サイトは気象庁とは関係がありません。

「]」の付いた年（観測の欠けがある年・今年のような年の途中）は順位と平均に入れていません。観測所の移転や観測方法の変更で、前後の年が厳密には比べられないことがあります（値欄の記号の説明）。
