このサイトについて

国民健康保険事業年報の保険者別諸率を、県ごと・市町村ごとに1ページへまとめ直しています。

出典と利用規約

厚生労働省「国民健康保険事業年報」保険者別データ 補足資料４ 保険者別諸率（e-Stat）。e-Stat 利用ルール（政府標準利用規約 第2.0版に準拠）に従い、加工して掲載しています。

当サイトが計算しているもの

県内の順位・県内市町村の単純平均・令和元年度からの増減。

載っていないもの

市町村が実際に課している料率・年収ごとの保険料の計算・減免。国民健康保険組合（医師・歯科医師・薬剤師など）は載せていません。

数字の読み方

1人当たり調定額は加入者の所得の水準でも上下します。料率の高さを比べるときは標準保険料率の列を見てください。標準保険料率は県が示す標準で、市町村の実際の料率とは違うことがあります。

更新

事業年報の新しい年度が公表されたら（年1回）作り直します。

運営者

個人が運営しています。国・自治体・データの提供元とは関係ありません。複数のサイトをまとめて運営しており、全体の方針は運営についてにあります。

誤りの報告・問い合わせ

数値の誤り・リンク切れ・削除の依頼は GitHub の Issues で受け付けています（GitHub のアカウントが必要です）。確認して、誤りであれば次の更新までに直します。

アクセス計測

訪問数を知るため、cookie を使わないアクセス計測（Cloudflare Web Analytics）を使っています。閲覧者を個人として識別・追跡する情報は集めていません。

広告

このサイトには Google AdSense の広告を表示しています。広告の配信に使われる cookie の扱いと無効にする方法はプライバシーポリシーに書いています。

ご利用にあたって

元データの誤り・更新の遅れ・当サイトの加工の誤りにより、実際と異なる場合があります。当サイトの情報を使って生じた損害について、運営者は責任を負いません。重要な判断の前には、各ページに記載した公式の情報源をご確認ください。

出典: 厚生労働省「国民健康保険事業年報」保険者別データ 補足資料４ 保険者別諸率（令和元年度・令和2年度・令和3年度・令和4年度・令和5年度・令和6年度・e-Stat）を加工して作成。 e-Stat 利用ルール（政府標準利用規約 第2.0版に準拠）に従っています。金額・率は原文の値で、県内の順位・平均・増減は当サイトが計算しています。国・県が内容を保証するものではありません。

「市町村標準保険料率」は都道府県が示す標準の料率で、市町村が実際に課している料率とは違うことがあります。実際の保険料は、お住まいの市町村の案内で確かめてください。
