このサイトについて

厚生労働省が公表している都道府県別の有効求人倍率を、都道府県ごとに1ページへまとめ直しています。

出典と利用規約

厚生労働省「一般職業紹介状況」長期時系列表 第11表の「有効求人倍率（季節調整値）」（パートタイムを含む一般・e-Stat 掲載の xlsx）。e-Stat の利用規約（政府標準利用規約 第2.0版に準拠）に従い、加工して掲載しています。

当サイトが計算しているもの

前月差・前年同月差・全国との差・47都道府県の中の順位（小数第2位で同じ値は同順位）・過去最高／最低・年ごとの最高／最低。倍率は原文の値を小数第2位で表示しています。

載っていないもの

実数（季節調整をしていない値）、新規求人倍率、職業別・雇用形態別の倍率、就業地別の倍率、市区町村・ハローワーク別の値は載せていません。

更新

厚生労働省が毎月の一般職業紹介状況を公表し、長期時系列表が更新されたら作り直します。季節調整値は過去に遡って改定されることがあり、そのときは過去の月の値も変わります。

運営者

個人が運営しています。国・自治体・データの提供元とは関係ありません。複数のサイトをまとめて運営しており、全体の方針は運営についてにあります。

誤りの報告・問い合わせ

数値の誤り・リンク切れ・削除の依頼は GitHub の Issues で受け付けています（GitHub のアカウントが必要です）。確認して、誤りであれば次の更新までに直します。

アクセス計測

訪問数を知るため、cookie を使わないアクセス計測（Cloudflare Web Analytics）を使っています。閲覧者を個人として識別・追跡する情報は集めていません。

広告

このサイトには Google AdSense の広告を表示しています。広告の配信に使われる cookie の扱いと無効にする方法はプライバシーポリシーに書いています。

ご利用にあたって

元データの誤り・更新の遅れ・当サイトの加工の誤りにより、実際と異なる場合があります。当サイトの情報を使って生じた損害について、運営者は責任を負いません。重要な判断の前には、各ページに記載した公式の情報源をご確認ください。

出典: 厚生労働省「一般職業紹介状況」長期時系列表 第11表「都道府県（受理地）別 有効求人倍率（季節調整値）」（パートタイムを含む一般・e-Stat）を加工して作成。 e-Stat 利用規約（政府標準利用規約 第2.0版に準拠）。倍率は原文の値を小数第2位で表示し、前月差・前年同月差・全国との差・順位・過去最高／最低は当サイトが計算しています。 本サイトは厚生労働省とは関係がありません。

都道府県の値は求人を受け付けたハローワークの所在地（受理地）で集計されたものです。季節調整値は新しい季節指数で過去に遡って改定されることがあります。
