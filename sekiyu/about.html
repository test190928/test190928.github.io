このサイトについて

資源エネルギー庁が毎週公表している給油所の小売価格を、都道府県ごとに1ページへまとめ直しています。

出典と利用規約

資源エネルギー庁「石油製品価格調査」の給油所小売価格の週次ファイル（調査は一般財団法人日本エネルギー経済研究所 石油情報センターへの委託）。資源エネルギー庁ウェブサイトの利用規約（公共データ利用規約 第1.0版に準拠）に従い、加工して掲載しています。

当サイトが計算しているもの

前回の調査・前年同週との差、47都道府県の中の順位（高い順・同額は同順位）、暦年の平均、冬（10月〜翌3月）の平均と最高値、掲載期間の最高値・最安値、何回続けて上がった・下がったか。いずれも毎週の調査値から計算しています。

載っていないもの

市区町村別・給油所ごとの価格、会員価格・セルフの別、2004年6月より前の都道府県別の値は載せていません（原文に都道府県別の値が無い期間があります）。原文で値が空欄の週（2011年3月14日・2011年3月22日）は表・グラフ・平均から外しています。灯油は給油所での価格で、ホームセンターや生協の価格は含みません。

更新

資源エネルギー庁の公表（原則毎週水曜日）のあとに作り直します。

運営者

個人が運営しています。国・自治体・データの提供元とは関係ありません。複数のサイトをまとめて運営しており、全体の方針は運営についてにあります。

誤りの報告・問い合わせ

数値の誤り・リンク切れ・削除の依頼は GitHub の Issues で受け付けています（GitHub のアカウントが必要です）。確認して、誤りであれば次の更新までに直します。

アクセス計測

訪問数を知るため、cookie を使わないアクセス計測（Cloudflare Web Analytics）を使っています。閲覧者を個人として識別・追跡する情報は集めていません。

広告

このサイトには Google AdSense の広告を表示しています。広告の配信に使われる cookie の扱いと無効にする方法はプライバシーポリシーに書いています。

ご利用にあたって

元データの誤り・更新の遅れ・当サイトの加工の誤りにより、実際と異なる場合があります。当サイトの情報を使って生じた損害について、運営者は責任を負いません。重要な判断の前には、各ページに記載した公式の情報源をご確認ください。

出典: 資源エネルギー庁「石油製品価格調査」給油所小売価格の週次ファイル（2026年10月5日調査分まで）を加工して作成。 資源エネルギー庁ウェブサイトの利用規約（公共データ利用規約 第1.0版に準拠）。価格は原文の値（消費税込みの現金価格）で、前回比・順位・平均・最高値などは当サイトが計算しています。 本サイトは資源エネルギー庁・石油情報センターとは関係がありません。

価格は各都道府県の給油所を対象にした調査の平均で、個々の給油所の価格ではありません。会員価格・セルフとフルの別・値引きは反映していません。
