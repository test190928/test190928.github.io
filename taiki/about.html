このサイトについて

こども家庭庁の保育所等関連状況取りまとめの市区町村別の申込者の状況を、県ごと・市町村ごとに1ページへまとめ直しています。

出典と利用規約

こども家庭庁「保育所等関連状況取りまとめ」（参考）申込者の状況。コピーライトポリシー（公共データ利用規約 第1.0版）に従い、加工して掲載しています。

当サイトが計算しているもの

県の合計・県内の順位・申込者に占める割合・3年の増減・「利用している」人数の合計。

ページのある市町村

3年のどれかで待機児童が1人以上いた市町村と、待機児童に数えない申込者（育児休業中・特定の保育園等のみ希望・求職活動休止）が10人以上いる市町村です。ほかの市町村は県の一覧にだけ載せています。

載っていないもの

保育所ごとの空き状況・入園の選考基準・市町村が独自に公表する数。

更新

取りまとめが公表されたら（年1回）作り直します。

運営者

個人が運営しています。国・自治体・データの提供元とは関係ありません。複数のサイトをまとめて運営しており、全体の方針は運営についてにあります。

誤りの報告・問い合わせ

数値の誤り・リンク切れ・削除の依頼は GitHub の Issues で受け付けています（GitHub のアカウントが必要です）。確認して、誤りであれば次の更新までに直します。

アクセス計測

訪問数を知るため、cookie を使わないアクセス計測（Cloudflare Web Analytics）を使っています。閲覧者を個人として識別・追跡する情報は集めていません。

ご利用にあたって

元データの誤り・更新の遅れ・当サイトの加工の誤りにより、実際と異なる場合があります。当サイトの情報を使って生じた損害について、運営者は責任を負いません。重要な判断の前には、各ページに記載した公式の情報源をご確認ください。

出典: こども家庭庁「保育所等関連状況取りまとめ」（参考）申込者の状況（令和5年4月1日・令和6年4月1日・令和7年4月1日）を加工して作成。 こども家庭庁コピーライトポリシー（公共データ利用規約 第1.0版）に従っています。人数は原文の値（市区町村からの報告を国が積み上げたもの）で、県内の順位・割合・増減は当サイトが計算しています。

待機児童・育児休業中・特定の保育園等のみ希望・求職活動休止の数え方は国の定義によります。市町村が独自に公表する数と違うことがあります。
